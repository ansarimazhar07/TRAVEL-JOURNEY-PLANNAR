# Future Scope

The current project is intentionally simple. Future versions could include:

1. Online train/flight booking links.
2. Hotel booking integration.
3. Payment gateway.
4. Google Maps route planning.
5. Better AI itinerary generation.
6. User reviews and ratings.
7. Trip sharing.
8. Email notifications.
9. Mobile application.
10. Expense charts.
11. Travel reminders.
12. Saved favorite destinations.

These features are outside the current course-project scope.
