# Requirements

## Functional Requirements

- User can browse destinations.
- User can view places.
- User can view hotels.
- User can search trains.
- User can search flights.
- User can check weather.
- User can generate an AI recommendation.
- User can create a trip.
- User can manage a simple itinerary.
- User can calculate a budget.
- User can register and log in.
- User can submit a contact message.

## Software Requirements

- Node.js
- React.js
- PHP 8+
- MySQL
- XAMPP
- Web browser
- VS Code

## External Services

- RailRadar API
- Amadeus API
- Gemini API
- Weather API
- OpenStreetMap/Leaflet

## Hardware Requirements

Minimum practical requirements:

- 4 GB RAM
- Dual-core processor
- 5 GB free storage
- Internet connection for external APIs

## Important Note

External API availability, free-tier limits, authentication methods, and endpoint details can change. Before final implementation, check the current documentation for each provider.
