# UI Pages

The project contains 19 simple pages/routes.

## 1. Home

Purpose:
- Introduction
- Search/plan button
- Popular destinations

## 2. About

Purpose:
- Explain project
- Explain main features

## 3. Destinations

Purpose:
- Display destination cards
- Basic search/filter

## 4. Destination Details

Purpose:
- Description
- Best time
- Places
- Hotels
- Weather link

## 5. Places

Purpose:
- Tourist place cards

## 6. Place Details

Purpose:
- Place description
- Entry fee
- Location
- Map link

## 7. Hotels

Purpose:
- Hotel cards
- Price
- Rating

## 8. Hotel Details

Purpose:
- Hotel details
- Facilities
- Location

## 9. Train Search

Purpose:
- Search real train information through RailRadar

Inputs:
- From
- To
- Date

## 10. Flight Search

Purpose:
- Search flight offers through Amadeus

Inputs:
- From
- To
- Date
- Travellers

## 11. Weather

Purpose:
- Show weather for selected city

## 12. AI Recommendation

Purpose:
- Ask Gemini for a simple travel plan

Inputs:
- Destination
- Days
- Budget
- Interests

## 13. Trip Planner

Purpose:
- Create a trip

## 14. My Itinerary

Purpose:
- View daily activities
- Add/delete activities

## 15. Budget

Purpose:
- Calculate estimated trip cost

## 16. Login

Purpose:
- User login

## 17. Register

Purpose:
- New account

## 18. Profile

Purpose:
- Display basic user information
- Show trips

## 19. Contact

Purpose:
- Send a message

## Navigation

Keep the navigation bar small:

```text
Logo | Home | Destinations | Plan Trip | Trains | Flights | My Trip | Login
```

Other pages can be reached from their related pages.
