# Travel Journey Planner

A simple Web Technologies course project built with React, PHP REST API, MySQL, and selected external APIs.

## Main Features

- Explore destinations
- View tourist places
- View simple hotel information
- Search real train information using RailRadar API
- Search flight offers using Amadeus API
- Get AI-based trip recommendations using Gemini API
- View weather information
- Create a simple trip
- Create a basic itinerary
- Calculate trip budget
- Basic login/register
- Contact form

## Technology Stack

- Frontend: React.js
- Styling: HTML5, CSS3
- Routing: React Router
- HTTP requests: Fetch or Axios
- Backend: PHP 8+
- API style: REST
- Database: MySQL
- Train data: RailRadar API
- Flight data: Amadeus API
- AI: Gemini API
- Weather: Weather API
- Map: Leaflet + OpenStreetMap
- Local development: XAMPP

## Project Principle

The application is intentionally simple. It is a college Web Technologies project, not a commercial travel-booking platform.

External APIs are used only for features where live/AI data is useful. Destinations, places, hotels, trips, itineraries, and expenses can be stored in MySQL.
